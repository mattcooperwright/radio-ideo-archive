# Radio IDEO archive

## Brand assets

Logo files live in `brand/logo/`. Read `brand/logo/README.md` before creating
any visual output for Radio IDEO; it lists each file, the brand colours, and
how the mark is constructed. Use the supplied files rather than redrawing the
logo.

## Typography

The brand typeface is FH Oscar, loaded from
`https://fonts.cdnfonts.com/css/fh-oscar-condensed-test` with the CSS family
`'FH Oscar Test', 'Manrope', sans-serif`. That package also contains
FH Oscar Condensed: do not use the Condensed faces.
Read `brand/typography.md` before setting any type.

## Firebase

The Firebase project ID is `radio-ideo-archive` (project number
1028299641494, under the ideo.com Google Cloud organisation). `.firebaserc`
sets it as the default, so Firebase CLI commands run from the repo root
target it without `--project`.
